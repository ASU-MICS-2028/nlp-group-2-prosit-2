# evidence/

Proof for each graded deliverable. Folders: `skeleton/`, `evaluation/`, `deploy/`, `deliverables/`.
Each deliverable is listed in the checklist in [PLAN.md](../PLAN.md) with the exact file name and who captures it.

## Naming
- Terminal output: `outputs_<part>_<what>.txt` (save with `command | tee evidence/<folder>/outputs_<part>_<what>.txt`)
- Screenshots: `<part>-<what>.png`
- Scripts: saved as they were run.

## Screenshot rules
- Show the page title and the URL or resource name.
- Nothing secret on screen (keys, tokens, `.env`).
- Before and after shots for anything that changes.
- Capture it **at the time**; things that were torn down or changed cannot be re-shot later.
- Evidence is never rewritten. Add a new file instead.
