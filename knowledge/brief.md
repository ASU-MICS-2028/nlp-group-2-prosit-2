# Brief (summary)

**Client story:** Mesora, an AI research lab in Ghana, believes coding agents for web apps should keep the frontend
and backend separate, talking through a well-defined API. Tools like Lovable and Replit let non-developers build web apps.
Mesora wants the same for **backend APIs**, through an interface friendly to non-developers.

**Our job:** build that platform as a team, and each person writes a technical report.

**Report**
- **Section A (individual, 3–5 pages):** how a model that only predicts the next token leads to agents, and how coding agents work.
  Topics: a instruction tuning, b preference-based learning, c alignment, d prompt engineering and chain-of-thought,
  e RAG, f agentic AI, g multi-agent systems, h reasoning and planning, i memory, j RLHF, k privacy and security of agentic AI,
  l human-in-the-loop, m coding agents, n perceive-plan-act and ReAct loops, o tool use, p decomposition and self-reflection,
  q Model Context Protocol, r orchestration. Include maths and visuals where appropriate, and always justify answers.
- **Section B (identical for all team members, 3–5 pages):** approach and justification, architecture, implementation
  choices and details, evaluation.

**Also:** a 10-minute team presentation summarising Section B in an engaging way; code on GitHub.
Page 1 of both slides and report must carry the GitHub link.

**Learning outcomes touched:** design, implement, evaluate and deploy LLM applications; read and implement research;
explain NLP concepts clearly to technical and non-technical audiences.
