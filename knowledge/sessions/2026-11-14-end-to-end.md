# 2026-11-14: End-to-end (W-9)

**Goal:** Make a request sent on the chat screen start a real build, shown live.

**What we found:** Nothing called the builder, so every project stayed on "waiting". The server never read `.env`.

**What we decided:**
- Until F-2, `POST /projects` starts the build at once, in FastAPI's `BackgroundTasks`, with the request as written.
- The server calls Opei's `build_with_retries` (not `build_project`), so `attempt` and `max_attempts` reach the screen.
- Start the server with `uvicorn ... --env-file .env`; no code reads the key.
- `GET /projects/{id}` gains `name`, `file_count`, `size_kb`, `tests_passed`, `tests_total` (null until the end).

**What changed:** `backend/projects.py` (`run_build`, `results`, `count_tests`, new fields), 6 tests in `backend/tests/test_projects.py`, contract note, W-9 section in `learnings/backend.md`, evidence of the first live run.

**Result:** run 1 failed cleanly on a slow, busy Gemini; run 2 ended `ready` (6 files, 10 of 10 tests). Decision D-017.
