# 2026-11-18 · F-18 stop a running build

Who: Nana, with Claude Code. Agreed with Perfect (the frontend is Perfect's area).

## Goal
Let the person stop a build while it runs, as coding agents do. The `stopped` status, its pill and its notice already existed, but nothing could set it.

## What we found
- `stopped` was already in the contract, `FINAL_STATUSES`, `StatusPill` and `BuildScreen`.
- Builds ran as a FastAPI background job with no handle to cancel. Running the retry loop as its own asyncio task gives one.
- The agent's tests run inside a tool without an `await`, so a stop during a test run waits for it to end (at most its time limit).
- F-14 was already Perfect's Ready screen, so this is F-18 (and D-022).

## What we decided
- `POST /projects/{id}/stop`: `202` at once; the build writes `stopped` itself. `409` when finished, `404` unknown, double stop harmless.
- Nothing of a stopped build is kept (no download, no live API).
- The page asks first ("Stop this build?") and ends the timeline with "Stopped by you".
- A cancel that is not the person's Stop (server shutdown) is not called "stopped".
